# My Little World

`v0.01` is a mobile-first Drawing Studio vertical slice built with Phaser 3, TypeScript, Vite, and a small localStorage save system.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite. The casual access phrase for this private prototype is supplied separately; it is intentionally not displayed in the game UI.

## Checks

```bash
npm run typecheck
npm test
npm run build
```

The Vite base path and Pages workflow target `https://corentis-88.github.io/my-little-world/`.
